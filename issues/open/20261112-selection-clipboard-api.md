# npm 公開 API の選択・コピー互換性を整理する

Status: open
Model: unknown
Created: 2026-11-12
Updated: 2026-11-12
Branch: research/20261112-selection-clipboard-api

## 概要

npm パッケージだけを利用するブラウザーで、表の範囲コピーと複数ページの文字選択を実現するために不足している公開 API を、再現テストとともに整理する。

## 背景

`bdf.mbt@2026.11.1` の利用側検証では、PDF の文字コピーは成功した一方、表の複数セル TSV/HTML コピー、ページをまたぐ選択、未表示ページの選択、XDW の本文・注釈のドラッグ選択が失敗したとの報告がある。描画成功と選択・コピー成功は別の条件である。

この報告は本リポジトリ単体の最新再現結果ではない。公開 main `18f4f4d0a96674fccd5332fde7cd03d7c896a03d` と最新 npm 配布物で再現範囲を確認する。

## 問題

利用側が必要とする `sheetClipboard(view, range)` 相当の TSV/HTML 取得契約が公開 Worker/client のどこで提供されるか不明確である。内部のセル直列化や文字層機能が存在していても、公開パッケージから使えることの証明にはならない。表示外セル、結合セル、Unicode、ページ間の選択順序についても、変換・文字索引・公開 API・UI のどの層に不足があるか未確定である。

## 目標

配布物を直接変更せずに選択・コピーを実装できる公開契約と不足を特定し、独立して修正できる単位に分ける。

## 対象外

- 配布済み npm ファイルへのパッチ適用。
- 実業務文書・組織情報を含む再現入力。
- フォント配信・フォント同梱、形式の追加、変換精度全般。
- この調査だけで全形式の選択互換性を保証すること。

## 提案する方針

1. 公開 Worker/client、型定義、ブラウザー API と内部セル/文字層実装の対応を確認する。
2. 実際に pack/install したパッケージと最小ブラウザーアプリで、合成 XLSX/CSV/表形式 BDF の範囲コピーを再現する。表示外・結合セル・Unicode を含める。
3. 合成の複数ページ BDF と文書で、表示済み/未表示ページをまたぐ文字選択を分けて検査する。XDW 注釈は既存 `20261109-xdw-annotation-index.md` と重複しないように切り分ける。
4. 必要な追加 API、既存 API の利用方法、UI 側で完結する責務を整理する。新 API の名称を既存報告の名称に固定しない。
5. 根因を確認したものだけ、小さい実装 issue と再現テストへ分割する。

## 受け入れ条件

- [ ] 公開版・main のリビジョン、ブラウザー、実行コマンドを記録する。
- [ ] TSV/HTML、表示外セル、結合セル、Unicode の期待値と実結果を示す。
- [ ] 複数ページ・未表示ページの選択について、描画と文字取得の合否を別々に示す。
- [ ] 公開 API 不足、文字索引不足、UI の問題、未再現を区別する。
- [ ] 必要な公開契約と制限、独立した修正単位を記録する。
- [ ] 正常な PDF コピー等の既存動作を回帰対象に含める。

## テスト計画

- package の pack/install smoke と型検査。
- Chromium の合成表で TSV の改行/タブと HTML のセル構造・エスケープを照合する。
- 再表示、ズーム、ページ移動、キャンセル後のコピーを確認する。
- クリップボード権限による失敗と API のデータ取得失敗を区別する。
- 未実行の形式・環境は未実行と記録し、検証可能な範囲の作業を止めない。

## リスク

ブラウザーの権限や利用側 UI による失敗をエンジンの欠陥と誤認する可能性がある。画面上の文字列だけからセルの論理順序や結合範囲を復元する方法は、表示外データを欠落させる可能性がある。
