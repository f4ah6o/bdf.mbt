# Music notation compatibility fixtures

These fixtures compare musical meter, key estimation, pitch spelling measure timelines, note quantization, clef selection, percussion mapping, note-value division, voice assignment, staff events, Bravura glyphs, staff positions, score preparation, measure spacing, system layout, drawing primitives, staff headers, rests, isolated note layouts, beams, basic staff drawings, ties, tuplets, lyrics and system marks with
shibukawa/bdf commit `4f9af52dca60be1eb0daade39f7dc41d6a1fe431`.
They exercise all key signatures, negative and positive pitch numbers,
spelling hints and deterministic duration histograms.

Run `moon build --target js` and
`npm run test:music-notation`. To regenerate, copy `generate_test.go` without
its first two lines to `converter/internal/music/codex_key_test.go` in the
upstream checkout, then run:

```sh
BDF_FIXTURE_ROOT=/path/to/bdf.mbt go test ./converter/internal/music -run '^TestCodexMusicKeys$' -count=1
```

Timeline fixtures use `generate_timeline_test.go` and
`TestCodexMusicTimeline` in the same way. Quantization fixtures use
`generate_quantize_test.go` and `TestCodexMusicQuantize`. Staff and percussion
fixtures use `generate_staff_test.go` and `TestCodexMusicStaff`. Note-value
fixtures use `generate_values_test.go` and `TestCodexMusicValues`. Voice
fixtures use `generate_voices_test.go` and `TestCodexMusicVoices`. Staff event
fixtures use `generate_events_test.go` and `TestCodexMusicEvents`.

Generate `convert/music/smufl_data.mbt` and `smufl_names.json` by copying
`generate_smufl_test.go` to the upstream `converter/internal/music/smufl`
package and running `TestCodexSMuFL`, then format the MoonBit package. The
`generate_glyph_test.go` fixture uses `TestCodexMusicGlyphs` in the upstream
`converter/internal/music` package and reads `smufl_names.json`. Staff position
and accidental fixtures use `generate_positions_test.go` and
`TestCodexMusicPositions`.

Prepared score fixtures use `generate_prepare_test.go` and
`TestCodexMusicPrepare`. The generator reconstructs upstream score objects
from `compat/midiinput/score.json`; the verifier parses the corresponding MIDI
files through this port before comparing the prepared score.

Measure column fixtures use `generate_columns_test.go` and
`TestCodexMusicColumns`, alongside the upstream copy of
`generate_prepare_test.go`. The fixtures include the upstream font-measured
lyric widths supplied to the MoonBit layout function.

System layout fixtures use `generate_systems_test.go` and
`TestCodexMusicSystems` alongside the upstream copy of
`generate_prepare_test.go`.

Primitive and skyline fixtures use `generate_primitives_test.go` and
`TestCodexMusicPrimitives`.

Staff header fixtures use `generate_headers_test.go` and
`TestCodexMusicHeaders` alongside `generate_prepare_test.go`.

Rest layout fixtures use `generate_rests_test.go` and
`TestCodexMusicRests` alongside `generate_prepare_test.go`.

Isolated note layout fixtures use `generate_notes_test.go` and
`TestCodexMusicNotes` alongside `generate_prepare_test.go`.

Beam layout fixtures use `generate_beams_test.go` and
`TestCodexMusicBeams` alongside `generate_prepare_test.go`.

Basic staff drawing fixtures use `generate_basic_staff_test.go` and
`TestCodexMusicBasicStaff` alongside `generate_prepare_test.go`.

Tie and tuplet fixtures use `generate_staff_marks_test.go` and
`TestCodexMusicStaffMarks` alongside `generate_prepare_test.go`.

Lyric drawing fixtures use `generate_staff_lyrics_test.go` and
`TestCodexMusicStaffLyrics` alongside `generate_prepare_test.go`.

`TestCodexMusicSystemMarks` alongside `generate_prepare_test.go`.
