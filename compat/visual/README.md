# Visual compatibility fixture

`fixture.bdf` was generated with `generate_fixture.go` using
[shibukawa/bdf v0.2.1](https://github.com/shibukawa/bdf/tree/v0.2.1)
(commit `4f9af52`). It exercises compressed parts, a child object, paths,
transforms, clipping, alpha, dashes, gradients, a raster image and pattern,
SVG, system and embedded-font text, transparency groups, blend modes, and alpha and luminosity masks with transfer functions. The PNG is synthesized by the
generator; `synthetic.ttf` is an original two-glyph font
generated by `generate_font.py` with fonttools 4.60.2.

`baseline.html` renders the fixture with the published upstream
`@bdfkit/core` and `@bdfkit/render` 0.2.1 packages. `moon.html` renders the
single-file bytes with the locally built MoonBit browser library. `split.html` renders the corresponding upstream-generated split document, including an external path, through the asynchronous loader; an unused part checks that loading is selective. Encrypted fixtures cover password-protected single and split documents and single and split documents protected for a synthetic P-256 key pair. The checked-in private key and password are test-only values. Both use the same
browser and page geometry. `compare.mjs` waits for each render to complete,
uses `vlmkit diff html` and `vlmkit diff agent`, rejects blank captures and
checks the unfiltered pixel difference at three viewport sizes. Reports and
screenshots are written to `_build/visual-diff/`.

To regenerate the fixture, check out the specified upstream revision and run:

```sh
python /absolute/path/to/bdf.mbt/compat/visual/generate_font.py
go run /absolute/path/to/bdf.mbt/compat/visual/generate_fixture.go /absolute/path/to/bdf.mbt/compat/visual/fixture.bdf /absolute/path/to/bdf.mbt/compat/visual/synthetic.ttf /absolute/path/to/bdf.mbt/compat/visual/split-fixture /absolute/path/to/bdf.mbt/compat/visual/encrypted-fixture
```

The snapshot covers only the fixture's operations. Additional fixtures are
needed to establish parity for other document features and real input formats.
