# 数式のテスト

GitHub と同じ書き方の数式です。インラインの $e^{i\pi} + 1 = 0$ や $`\sqrt{2} \approx 1.414`$ は行の中に、
値段の $5 と $10 は数式になりません。二次方程式 $ax^2 + bx + c = 0$ の解は

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

です。段落の中の $$\sum_{k=1}^{n} k = \frac{n(n+1)}{2}$$ は独立した行になります。

```math
\begin{aligned}
\nabla \cdot \mathbf{E} &= \frac{\rho}{\varepsilon_0} \\
\nabla \times \mathbf{B} &= \mu_0 \mathbf{J} + \mu_0 \varepsilon_0 \frac{\partial \mathbf{E}}{\partial t}
\end{aligned}
```
