# JPEG 2000 decoder

This package is vendored from [trkbt10/jpeg2000](https://github.com/trkbt10/jpeg2000_mbt) 0.2.0 under the
Apache License 2.0 (see [LICENSE](LICENSE)). Package import paths were rewritten
for `f4ah6o/bdf/convert/pdf/jpx`; the command-line tools, test corpus and
native-only test configuration were removed. `decode_with_layout` exposes the
decoded sample layout used by the PDF JPX image path.
