ROUND TRIP

BDF から描き戻す

表示している BDF を、PDF・Markdown・検索用テキストに書き出します。変換はこのブラウザの中で動きます。

対象: 文書を開いてください

ページを PDF ファイルに書き出します。文書のフォントを埋め込み、リンクも残します。グラデーションは近似し、マスク・フィルタ・画像・タグ付き構造は省略します。できたファイルはブラウザの PDF ビューアで下に表示します。

新しいタブで開く PDF を保存

bdf pdf demo.bdf demo-from-bdf.pdf

見出し・リスト・表を保ったまま Markdown に書き出します。図は zip に同梱するか、データ URL で埋め込むか、省けます。

保存
bdf markdown demo.bdf out/

ページごとのテキストと文書のメタデータを JSON に取り出します。1 ページが 1 レコードで、検索エンジンに渡せます。

保存

          
bdf text demo.bdf demo-text.json

        

        

          
同じレコードを MiniSearch でブラウザの中に索引づけします。1 ページが 1 レコード、日本語は隣り合う 2 文字の組（バイグラム）で索引づけます。ヒットを選ぶと上の文書がそのページを開きます。

          

          

          
import MiniSearch from "minisearch";

SAME INPUT · UPSTREAM + BDF.MBT
上流 BDF (Go) と bdf.mbt の計測
同じ20ページの BDF と20ページの PDF を、上流 BDF (Go) と bdf.mbt の JavaScript / wasm-gc 実装で処理した実測値です。上流 Go は CLI のプロセス起動とファイル書き出し込み、bdf.mbt はブラウザ内のウォーム済み関数。ウォームアップ2回の後に7回測った中央値です。

上流の Office 変換カードは入力が異なるため、ここでは同じ BDF / PDF を使った上流 BDF (Go) CLI と比較しています。上流 Go は CLI 実行（起動込み）、bdf.mbt はブラウザ内のメモリ内処理です。PDF の圧縮・フォント埋め込み方式は異なるため、時間は実装と実行方法の目安です。MiniSearch は bdf.mbt の JavaScript 索引のみなので、上流と wasm-gc の列は「—」です。
