PROJECT STATUS

Porting coverage

shibukawa/bdf の MoonBit への移植と検証の範囲です。機能の一部が動作することは、形式全体の互換性を保証するものではありません。

デモで試せる範囲

  • BDF 表示：同梱の事前変換済み文書を表示、検索、ページ移動できます。20 ページの表示をブラウザで検証しています。
  • CSV / TSV：ブラウザ内で BDF に変換し、表を表示します。変換結果は上流の比較用データで検証しています。
  • Excel (XLSX)：対応するワークシートを変換します。単一シートに PNG 1 枚を含む画像サンプルも検証しています。フォントディレクトリを渡した場合は先頭のフォントをメトリクスと埋め込みに使い、渡さない場合は推定メトリクスを使用します。未対応の書式や機能は、エラーになる場合や表示に反映されない場合があります。変換可能な範囲は 変換器の実装 と 比較テストをご確認ください。
  • PDF：ページ木、図形、テキスト、タイルパターン、JPX/JBIG2 画像、Type3 グリフ、フォームの URI アクション、暗号化 PDF（標準セキュリティハンドラの R2/R3/R4/R6）をブラウザ内で変換します。JBIG2 は MMR の汎用領域のみ、暗号化は R5、色キーマスク付きのエンコード画像などが未対応です。暗号化サンプルのパスワードは demo です。
  • 画像・デザイン：BMP、ICO、JPEG、PNG、GIF、WebP、AVIF、SVG、AI（PDF 互換）、TIFF、Photoshop（PSD/PSB）、EMF/WMF、InDesign（IDML）、Visio（VSDX）、EPUB、HTML、Markdown、音声、HP-GL/2 プロット、Jw_cad 図面、DXF 図面、SXF の SFC 図面、CGM、Gerber、KiCad ボード、draw.io、Type 1 埋め込み PDF、Parquet テーブルを変換します。DXF はレイアウト、バイナリ、ハッチ、非上面の押し出しを、SXF は P21/P2Z、寸法、ラベル、ハッチを、CGM はクリアテキスト、gzip、セル配列、タイル、ハッチを、Gerber は zip、完全な Excellon ヘッダー、クリア極性、基板ページの自動スケーリングを、KiCad は回路図、プロジェクト、裏面・レイヤービュー、ゾーンを省略します。draw.io は非圧縮・圧縮 XML と SVG/PNG エクスポートを読み、ダイアグラムごとの固定ビュー、内容に合わせたページ、レイヤー、mxGraph/flowchart/UML/BPMN の実用ステンシル、形状輪郭へのエッジ接続、エッジラベル、HTML ラベル、LaTeX の簡易 Unicode 変換に対応します。AWS/Azure/GCP/Cisco の大規模アイコン表、本格的な数式組版、画像、ラインジャンプ、障害物回避を含む完全なルーティングは未対応で、直線・曲線・実用的な直交/エルボルートと始点・終点マーカーには対応します。未知のステンシルは警告付きの外接矩形で描画します。Parquet は非圧縮・Snappy・GZIP・Brotli・Zstandard・LZ4、Data Page v1/v2、複数の行グループ、辞書・RLE・DELTA・BYTE_STREAM_SPLIT、日付・タイムスタンプ・10 進数、JSON 風のネストに対応します。WKB ジオメトリは WKT に変換し、WKT 形式のジオメトリ列と Variant version 1 も表示します。暗号化 Parquet、Variant version 2 以降は未対応で、複数の行グループ専用の比較フィクスチャは未整備です。HP-GL/2 は PCL/HP RTL ラスタジョブの一部を警告付きで省略します。SVG はデモのブラウザテストでも確認しています。TIFF の JPEG 圧縮ページ、合成画像のない PSD、メタファイルのパスや EMF+、IDML のフレーム間テキスト流し込み、Visio のテーマ・影・画像、共通テキストエンジンの完全なフォントメトリクスと表組、リーダーモードの CSS・リモート画像・固定レイアウト EPUB、音声の MP4 タグ・同期歌詞・チャプター・DRM は未対応です。
  • フォント見本：TrueType と WOFF2 の入力から見本を生成します。文字表、グリフ一覧やフォント情報を表示できます。デモでの入力と表示を検証しています。

移植を進めている範囲

BDF の読み書き、描画、フォントや表の処理などを段階的に移植しています。各機能の対応・制約と比較テストは README と compat のテストをご覧ください。

今後の対応

各形式の未対応機能と上流ビューアの全機能の移植は継続中です。デモは PDF サンプルもブラウザ内で変換しますが、上流の全機能を示すものではありません。未検証の機能は検証済みとして扱いません。

このページは公開デモの説明です。最新の実装状況はリポジトリの README とテストを確認してください。

shibukawa/bdf から独立して移植した非公式プロジェクトです。上流の公式提供・提携ではありません。
