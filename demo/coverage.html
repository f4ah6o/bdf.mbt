PROJECT STATUS

Porting coverage

shibukawa/bdf の MoonBit への移植と検証の範囲です。機能の一部が動作することは、形式全体の互換性を保証するものではありません。

デモで試せる範囲

  • BDF 表示：同梱の事前変換済み文書を表示、検索、ページ移動できます。20 ページの表示をブラウザで検証しています。
  • CSV / TSV：ブラウザ内で BDF に変換し、表を表示します。変換結果は上流の比較用データで検証しています。
  • Excel (XLSX)：対応するワークシートを変換します。単一シートに PNG 1 枚を含む画像サンプルも検証しています。フォントは埋め込まず推定メトリクスを使用します。未対応の書式や機能は、エラーになる場合や表示に反映されない場合があります。変換可能な範囲は 変換器の実装 と 比較テストをご確認ください。
  • 画像・デザイン：BMP、ICO、JPEG、PNG、GIF、WebP、AVIF、SVG、AI（PDF 互換）、TIFF、Photoshop（PSD/PSB）、EMF/WMF、InDesign（IDML）、Visio（VSDX）、EPUB、HTML、Markdown、音声、HP-GL/2 プロット、Jw_cad 図面、DXF 図面、SXF の SFC 図面、CGM、Gerber、KiCad ボード、draw.io を変換します。DXF はレイアウト、バイナリ、ハッチ、非上面の押し出しを、SXF は P21/P2Z、寸法、ラベル、ハッチを、CGM はクリアテキスト、gzip、セル配列、タイル、ハッチを、Gerber は zip、完全な Excellon ヘッダー、クリア極性、基板ページの自動スケーリングを、KiCad は回路図、プロジェクト、裏面・レイヤービュー、ゾーンを、draw.io は圧縮、ステンシル、HTML/数式、自動レイアウトを省略します。HP-GL/2 は PCL/HP RTL ラスタジョブの一部を警告付きで省略します。SVG はデモのブラウザテストでも確認しています。TIFF の JPEG 圧縮ページ、合成画像のない PSD、メタファイルのパスや EMF+、IDML のフレーム間テキスト流し込み、Visio のテーマ・影・画像、共通テキストエンジンの完全なフォントメトリクスと表組、リーダーモードの CSS・リモート画像・固定レイアウト EPUB、音声の MP4 タグ・同期歌詞・チャプター・DRM は未対応です。
  • フォント見本：TrueType と WOFF2 の入力から見本を生成します。文字表、グリフ一覧やフォント情報を表示できます。デモでの入力と表示を検証しています。

移植を進めている範囲

BDF の読み書き、描画、フォントや表の処理などを段階的に移植しています。各機能の対応・制約と比較テストは README と compat のテストをご覧ください。

今後の対応

Visio、IDML、EPUB、HTML、Markdown、音声、CAD などの入力変換器や、上流のビューアの全機能は移植途中です。デモの PDF サンプルは事前変換した BDF であり、ブラウザ内の PDF 変換を示すものではありません。未検証の機能は検証済みとして扱いません。

このページは公開デモの説明です。最新の実装状況はリポジトリの README とテストを確認してください。

shibukawa/bdf から独立して移植した非公式プロジェクトです。上流の公式提供・提携ではありません。
