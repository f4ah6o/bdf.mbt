DOCUMENT FORMATS

形式の説明

BDF 文書

BDF はブラウザでの文書プレビュー向けの形式です。描画情報やテキストを含む文書を表示し、ページ移動や検索ができます。デモのサンプルは PDF から事前に作成した BDF です。

ビューアへ

CSV / TSV

区切り文字で行と列を表すテキストを、ブラウザ内で BDF の表に変換します。

ビューアへ

Excel (XLSX)

対応するワークシートをブラウザ内で BDF の表に変換します。表示範囲や対応していない機能については Porting coverage をご覧ください。

ビューアへ

Word (DOCX)

段落と書式付きテキストを中心とした限定的な Word 文書を BDF に変換します。表はタブ区切りのテキストとして変換し、インライン画像は切り抜きも含めて埋め込み、番号付きリストとヘッダー・フッターも変換します。先頭ページ・偶数ページ用ヘッダーにも対応します。EMF/WMF 画像はメタファイルの対応サブセットで再生します。ヘッダー画像は未対応です。

ビューアへ

PowerPoint (PPTX)

スライド上の図形の塗りとテキストを中心とした限定的なプレゼンテーションを BDF に変換します。画像は埋め込み、テーマ色・輝度修飾・テーマフォントも解決します。レイアウトの背景・装飾とプレースホルダー位置の継承も行います。プレースホルダーの位置と既定の文字書式（サイズ・色・太字・斜体・フォント）を継承します。表はタブ区切りのテキストとして変換し、矩形・角丸矩形・楕円の塗りと枠線、塗り・画像の透明度、画像の切り抜き、図形の回転も描画します。棒グラフ・折れ線グラフ・円グラフも描画します。他のグラフ形式は未対応です。グループ回転は図形と文字に適用されます。

ビューアへ

PDF

ページ木、図形、テキスト、画像、注釈などを BDF に変換します。埋め込み Type 1 フォントは CFF に変換して埋め込みます。未対応の PDF 機能は明示的なエラーになります。

ビューアへ

HP-GL/2 プロット

HP-GL/2 と HP-GL のプロットファイルを、用紙サイズとペン設定に従って BDF のベクタページに変換します。線種、塗り、ラベル、ラスタ画像の一部に対応します。PCL/HP RTL のラスタジョブは警告付きで HP-GL/2 部分のみを変換します。

ビューアへ

Jw_cad (JWW)

Jw_cad の図面を用紙サイズのベクタページに変換します。線、円弧、楕円、点、文字、寸法、ソリッド、ブロックを、レイヤーグループと線種・色に従って描画します。用紙外の図形に合わせてページを広げます。

ビューアへ

AutoCAD DXF

ASCII DXF のモデル空間を BDF のベクタページに変換します。線、ポリライン、円、円弧、楕円、スプライン、文字、ソリッド、ブロックを描画します。レイアウト、バイナリ DXF、ハッチ、非上面の押し出しは未対応です。

ビューアへ

SXF

SXF の SFC テキスト形式を BDF のベクタページに変換します。用紙、レイヤー、色、線種、線幅、線、ポリライン、円、円弧、楕円、文字、点マーカー、スプライン、クロソイド、複合図形に対応します。P21/P2Z、寸法、ラベル、ハッチは未対応です。

ビューアへ

CGM

バイナリ CGM の各ピクチャを BDF のページに変換します。線、マーカー、ポリゴン、矩形、円、円弧、楕円、テキスト、線・塗り・文字属性に対応します。クリアテキスト、gzip、セル配列、タイル、ハッチは未対応です。

ビューアへ

Gerber

単一の RS-274X Gerber ファイルを BDF のベクタページに変換します。線、円弧、リージョン、フラッシュ、標準アパーチャと簡易マクロに対応します。基板ページの自動スケーリング、zip、完全な Excellon ヘッダー、クリア極性は未対応です。

ビューアへ

KiCad

KiCad のボード（.kicad_pcb）を前面ビューの BDF ページに変換します。Edge.Cuts、トラック、ビア、フットプリントのパッド、Reference/Value テキストに対応します。回路図、プロジェクト/zip、裏面・レイヤービュー、ゾーン、3D モデルは未対応です。

ビューアへ

draw.io

非圧縮 XML の最初のダイアグラムを BDF ページに変換します。矩形・楕円・テキスト、塗り・線・文字色、単純なエッジとラベルに対応します。圧縮ダイアグラム、ステンシル、HTML/数式、自動折り返し、エッジルーティング、ページ自動フィットは未対応です。

ビューアへ

Parquet

フラットな Parquet テーブルを BDF の表に変換します。Snappy/GZIP/Brotli/ZSTD/LZ4、Data Page v1/v2、辞書・RLE・DELTA・BYTE_STREAM_SPLIT、ネストした列に対応します。WKB ジオメトリと Variant は未対応です。

ビューアへ

画像

SVG、PNG、JPEG などの画像を BDF のページに変換し、ビューアで表示します。

ビューアへ

フォント

TrueType と WOFF2 をブラウザ内で BDF のフォント見本に変換し、文字の形やフォント情報を表示します。

ビューアへ

Adobe Illustrator (AI)

PDF 互換で保存された Illustrator 9 以降のアートボードを、PDF 変換器で BDF にします。PostScript 形式や PDF 内容のないファイルは明示的なエラーになります。

ビューアへ

TIFF

複数ページの TIFF/BigTIFF をページごとに BDF にします。None、PackBits、LZW、Deflate、CCITT G3/G4 圧縮と、2値・グレー・パレット・RGB・CMYK・アルファに対応します。JPEG 圧縮ページは警告付きで空白になります。

ビューアへ

Photoshop (PSD/PSB)

Photoshop がファイル内に保存した合成画像を、アートボード単位のページとして BDF にします。合成画像のないファイル（Maximize Compatibility 無効）は、レイヤー合成が未対応のため明示的なエラーになります。

ビューアへ

Windows メタファイル (EMF/WMF)

EMF/WMF の描画レコードを再生して BDF のベクタページにします。線、ポリゴン、矩形、楕円、テキスト、ビットマップなどに対応し、パスや EMF+ など一部の機能は警告付きで省略します。

ビューアへ

InDesign (IDML)

IDML パッケージのスプレッドとマスタースプレッド、ページ、レイヤー、図形、埋め込み画像、ストーリーを BDF に変換します。テキストは最初のフレームに描画し、フレーム間の流し込みは未対応です。リンク画像や表組も未対応です。

ビューアへ

Visio (VSDX)

Visio 2013 以降の VSDX パッケージを、前景ページと背景ページ、マスター、レイヤー、ShapeSheet の図形、塗り・線、テキストから BDF に変換します。テーマのクイックスタイル、影、ハイパーリンク、埋め込み画像は未対応です。

ビューアへ

EPUB / HTML / Markdown

EPUB のコンテナと spine、HTML の見出し・段落・リスト・コード・引用・表、Markdown の front matter・見出し・リスト・タスク・コードフェンス・引用・表・リンクを、共通のリーダーモードで A4 ページに組みます。Readability 抽出、CSS、リモート画像、固定レイアウト EPUB、MHTML、フォント埋め込みは未対応です。

ビューアへ

音声

MP3、AAC/M4A、FLAC、Ogg Vorbis/Opus、WAV、AIFF のタグ・カバー・歌詞・再生情報を1ページのカードにします。MP4/iTunes タグ、Ogg の再生時間、同期歌詞、チャプター、DRM は未対応です。

ビューアへ
