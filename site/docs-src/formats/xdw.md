# DocuWorks

富士フイルムビジネスイノベーションの DocuWorks(`.xdw`)とバインダー(`.xbd`)を、ブラウザの中で開きます。紙をスキャンしたページと、アプリケーションが描いたベクタのページが混ざる形式で、BDF は各ページの描画レコード(DocuWorks ドライバが書き込んだ Windows メタファイル、DocuWorks 独自の圧縮パス・画像レコード、JPEG の断片)を BDF の命令に置き換えて、1 ページをそのままの大きさと向きで持っていきます。

## 試してみる

[ビューア](https://f4ah6o.github.io/bdf.mbt/viewer/)にファイルをドロップするか、サンプルを試してください。[注釈つきの 1 ページ](https://f4ah6o.github.io/bdf.mbt/viewer/?file=samples/demo.xdw)です。

## DocuWorks(`.xdw`、`.xbd`)

`convert/xdw` は、ファイルを末尾のトレーラから読みます。DocuWorks の保存は「追記」であり、各世代のセグメントがエントリとプロパティブロック(オブジェクトツリー)を前の世代に重ねて持つため、最新のトレーラが指すエントリだけを使います。プロパティブロックとベクタのページの本文は LHA の `-lh5-` ビットストリーム(生ストリームでアーカイブヘッダなし)で圧縮されていて、展開したオブジェクトツリーからページ → 配置 → コンテンツ/注釈をたどります。

ページの本文は 4 種類あります。Windows メタファイル(EMF/WMF)として記録されたベクタページ、DocuWorks ドライバの GDI コメントレコード(`DW02`–`DW06` のパスとクリップ、`DWa`/`DWb`/`DWc` の画像、点を間引き符号化した図形)、JPEG 断片で描かれるスキャンページ、DIB のビットマップページ。注釈(テキスト、付箋、日付印、蛍光ペン、図形)は、DocuWorks が注釈自体の描画をすぐ使える形で持っているので、ページ本文と同じ手順で描きます。蛍光ペン(`R2_MASKPEN`)と透けて貼る画像(SRCAND)は、下の文字を消さずに乗る、のせる描画になります。バインダー(`.xbd`)は、文書ごとのページ範囲を保ったまま通しのページに展開します。

パスワードや証明書で保護された文書(プロパティとエントリが暗号化されているもの)は開かず、「保護された文書」として止まります。署名つきの文書は開けます(署名の検証は行いません)。

| オプション | 値 | 既定 |
|---|---|---|
| `-param pages=` | 表示するページ(例 `1,3-5`) | すべて |
| `-param include_hidden=` | `1` で、のちに描かれた不透明な塗りで完全に覆われた文字もテキストに残す | `0` |

書式の解析は、[EZPZ File XDW](https://github.com/ezpzfile/ezpzfile-xdw)(MIT ライセンス。書式仕様 [XDW-FORMAT.md](https://github.com/ezpzfile/ezpzfile-xdw/blob/main/docs/spec/XDW-FORMAT.md))を参考にして行いました。bdf.mbt の `convert/xdw` は、その読み取り・描画エンジンを MoonBit に移植したものです。
