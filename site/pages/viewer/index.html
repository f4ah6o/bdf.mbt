ビューア

ファイルをドロップすると、ブラウザの中で BDF に変換して表示します。PDF・Word・PowerPoint・Excel・CSV・Markdown・EPUB・画像・フォント・CAD などに対応し、ファイルはどこにも送られません。

ここにファイルをドロップするか、 を押してください。

–

暗号化 PDF はここに入力してください。サンプルのパスワードは demo です。
文書を開いてください BDF を保存

BDF から描き戻す

開いている BDF を、PDF・Markdown・検索用テキストに書き出します。書き出しは wasm-gc にコンパイルした MoonBit のコードが行います。

ページを PDF ファイルに書き出します。文書のフォントを埋め込み、タグ付きにすれば見出しや表の構造も残ります。できたファイルは、ブラウザ自身の PDF ビューアで下に表示します。

新しいタブで開く PDF を保存

文書を Markdown に書き出します。見出し・リスト・表はそのまま。図は zip にファイルとして同梱するか、データ URL で本文に埋め込むか、省きます。

保存

ページごとのテキストと文書のメタデータを JSON に取り出します。サーバーが検索エンジンに渡すものと同じ形で、1 ページが 1 レコードです。

保存

同じレコードを MiniSearch で索引づけし、ヒットからそのページを開きます。
